An entry for the [make.fun bounty "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329) ($35 USDC).

`main.py` writes one original one-line joke about working beside AI coding
agents to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. To write elsewhere, set
`MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/joke-out python3 main.py
```

No network, Python standard library only.
